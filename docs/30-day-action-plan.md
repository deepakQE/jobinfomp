# 30-Day Action Plan for Jobinfo MP

## Goal
Build stronger mobile-first utility, improve trust, increase search visibility, and turn the site into a faster job-alert destination than competitors.

## What Competitors Usually Win On
- More landing pages for result, admit card, answer key, syllabus, and state-wise searches.
- Strong urgency words in titles and summaries.
- Faster browsing via category and qualification filters.
- Telegram/WhatsApp alert loops.
- Rich detail pages with FAQs, dates, and official links.

## What Search Console Already Tells Us
- Railway and RRB queries are already getting impressions.
- `railway job`, `railway technician vacancy`, and `rrb recruitment 2026` are the highest-signal search themes.
- Indexing still has many discovered-but-not-indexed pages.
- The homepage and key job pages need more internal discovery support.

## Week 1: Fix Discovery
- Add qualification filters: 10th Pass, 12th Pass, Graduate, Diploma, ITI.
- Add state filters: MP, Railway, SSC, Bank, Police.
- Add more internal links from home and category pages to high-value job pages.
- Improve titles with clearer job keywords and last-date phrases.

## Week 2: Build Trust
- Expand About and Contact pages.
- Add author/owner identity and Telegram channel references.
- Add FAQ blocks to job detail pages.
- Add “related notification” links on result and answer-key pages.

## Week 3: Build Search Coverage
- Create landing pages for:
  - Railway Jobs
  - RRB Technician Vacancy
  - Result Updates
  - Admit Card Updates
  - Answer Key Updates
  - Syllabus pages
- Add category-specific intro text that matches search intent.
- Make sure each page has a real H1 and clean H2 sections.

## Week 4: Improve Repeat Visits
- Keep Telegram CTA visible in footer and contact page.
- Add WhatsApp or email later only if it fits your audience.
- Add a stronger top hero section for returning users.
- Review Search Console for pages with impressions but low clicks and improve those titles/descriptions.

## Content Rules
- Publish faster than competitors, but only after verifying official data.
- Use simple, direct, search-friendly titles.
- Put the last date, vacancy count, and post type near the top.
- Link every result/answer-key page back to its original notification when available.

## Safe Data Strategy
- Use official public sources only.
- Prefer official web pages, sitemaps, RSS feeds, public notices, and open PDFs.
- Avoid bypassing logins, captchas, or any access controls.
- Validate scraped details against the official source before publishing.

## Daily Data Update Workflow
- Check the top-search terms in Search Console first.
- Pull new notices from official pages, not from copied summaries.
- Rewrite the title to include role, vacancy count, and last date.
- Put the original notification page first, then result/answer key follow-ups.
- Link related pages together so users can move from notification to result without searching again.

## Priority Metrics
- Clicks from Search Console.
- Indexed pages.
- Mobile engagement.
- Telegram joins.
- Repeat visits from result and admit card pages.
